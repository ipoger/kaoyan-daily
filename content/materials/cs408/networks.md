# 计算机网络：分层、可靠传输与路由

## 一、分层

| 层 | 典型协议 / 设备 |
| --- | --- |
| 应用层 | HTTP、DNS、SMTP |
| 传输层 | TCP、UDP |
| 网络层 | IP、ICMP、ARP（常归网络层） |
| 数据链路层 | Ethernet、PPP、交换机 |
| 物理层 | 集线器、中继器 |

## 二、TCP 与 UDP

TCP：面向连接、可靠、字节流、拥塞控制、流量控制。

UDP：无连接、不可靠、首部 8 B、支持多播/广播。

TCP 三次握手：

1. SYN；
2. SYN + ACK；
3. ACK。

四次挥手：FIN、ACK、FIN、ACK。

## 三、IP 与子网

IPv4 首部固定 20 B。MTU 1500 B 时：

$$MSS=1500-20(\text{IP})-20(\text{TCP})=1460\text{ B}$$

子网 /26：主机位 6 位，可用地址 $2^6-2=62$。

CIDR 路由：最长前缀匹配。

## 四、可靠传输

停止等待：发送一帧，等 ACK。

后退 N 帧（GBN）：累计确认，出错重传从丢失帧开始的所有帧。

选择重传（SR）：只重传出错帧，需要接收窗口。

## 五、拥塞控制

- 慢开始：cwnd 每 RTT 翻倍；
- 拥塞避免：每 RTT 加 1；
- 快重传：收到 3 个重复 ACK 立即重传；
- 快恢复：ssthresh 减半，cwnd 从 ssthresh 开始。

## 六、路由

- RIP：距离向量，最大跳数 15，16 表示不可达；
- OSPF：链路状态，Dijkstra；
- BGP：自治系统之间。

## 七、易错点

- 路由器隔离广播域，交换机不隔离广播域。
- ARP 解析 IP → MAC，只在局域网内有效。
- TCP 的可靠传输依赖序号、确认、重传，不是“网络层保证”。
- 计算子网时先确定借了几位，再算网络地址和广播地址。
