# 阅读：先题干，再定位，最后排除

阅读理解的核心不是“读完全文”，而是**用题干定位信息，再用原文证据排除选项**。

## 一、做题顺序

1. 读题干，圈出定位词（人名、年份、专有名词、核心名词）。
2. 回原文找同义替换，而不是找原词。
3. 读定位句及其上下各一句。
4. 先排除“绝对化、无中生有、偷换概念”的选项。
5. 最后在剩余选项中比较“范围”和“态度”。

## 二、六种常见题型

| 题型 | 关键动作 |
| --- | --- |
| 细节题 | 定位句同义替换 |
| 推断题 | 只推一步，不脑补 |
| 例证题 | 例子服务于观点，往前后找论点 |
| 词义句意题 | 看上下文逻辑，不看构词法 |
| 态度题 | 抓形容词、副词、转折词 |
| 主旨题 | 看首末段和每段首句，选覆盖全文的选项 |

## 三、干扰项特征

- **绝对化**：all, never, only, completely；
- **偷换范围**：把 some 换成 all，把 may 换成 will；
- **因果倒置**：原文 A 导致 B，选项说 B 导致 A；
- **张冠李戴**：把甲的观点安到乙头上；
- **常识干扰**：选项本身正确，但原文没提。

## 四、精读一篇真题的流程

1. 限时做题，不对答案；
2. 对答案，只标错题；
3. 回原文找每道题的证据句；
4. 查生词，但只记“影响理解”的词；
5. 翻译长难句 2–3 句；
6. 第二天只看错题证据句。

## 五、时间分配

一篇阅读建议 16–18 分钟：

- 读题干 2 分钟；
- 定位与做题 10 分钟；
- 检查 3 分钟；
- 剩下时间处理难题。

不要在一道题上耗超过 3 分钟。先拿稳细节题，再回头处理主旨和推断。
