# 极限与连续：先把“未定式”拆开

极限题看起来千变万化，真正要判断的只有两件事：**是什么型**，以及**用哪种等价替换最省事**。

## 一、七种未定式

$$\frac00,\quad \frac{\infty}{\infty},\quad 0\cdot\infty,\quad \infty-\infty,\quad 1^\infty,\quad 0^0,\quad \infty^0$$

后三种是幂指型，统一写成

$$u^v=e^{v\ln u}$$

再处理指数上的极限。

## 二、等价无穷小（$x\to0$）

| 函数 | 等价于 |
| --- | --- |
| $\sin x,\tan x,\arcsin x,\arctan x$ | $x$ |
| $1-\cos x$ | $\frac12x^2$ |
| $e^x-1$ | $x$ |
| $\ln(1+x)$ | $x$ |
| $(1+x)^\alpha-1$ | $\alpha x$ |
| $x-\sin x$ | $\frac16x^3$ |
| $\tan x-x$ | $\frac13x^3$ |

> 等价替换只能用于**乘除的整体因子**，不能随手替换加减中的某一项。加减场景优先泰勒展开。

## 三、常用套路

1. **分母是 $x^k$**：把分子泰勒展开到 $x^k$，对比系数。
2. **根式差**：先有理化。
3. **$1^\infty$**：取对数，或直接用 $\ln(1+u)\sim u$。
4. **数列极限**：先看是否能用夹逼；$n$ 项和可以尝试定积分定义。
5. **分段点 / 绝对值**：分别算左右极限，不要直接求导。

## 四、连续与间断点

$f$ 在 $x_0$ 连续，需要

$$\lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=f(x_0)$$

间断点分类看左右极限：

- 左右极限都存在：第一类（可去 / 跳跃）；
- 至少一个不存在：第二类（无穷 / 振荡）。

## 五、一个典型例子

求

$$\lim_{x\to0}\frac{\tan x-\sin x}{x^3}$$

先变形：

$$\tan x-\sin x=\sin x\left(\frac1{\cos x}-1\right)
=\sin x\cdot\frac{1-\cos x}{\cos x}$$

分子等价于 $x\cdot\frac{x^2}{2}=\frac{x^3}{2}$，所以极限是 $\frac12$。

**易错点**：不要把 $\tan x-\sin x$ 中的 $\tan x$ 直接换成 $x$、$\sin x$ 也换成 $x$，否则会得到 $0$。加减结构要么通分，要么泰勒展开。

## 六、复盘清单

- 先代值判断型，再动手。
- 看到根号差先有理化。
- 看到 $1^\infty$ 先取对数。
- 看到 $x-\sin x$、$\tan x-x$ 想到三阶等价。
- 最后检查：有没有在加减中乱用等价无穷小。
